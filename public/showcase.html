One operating contract

Every harness — regardless of which company's model powers it — is trained to the same standard: think before acting, verify before claiming, lead with the outcome. The contract ships as skills installed into each harness, so a GLM-powered agent works the way the lab's best agent works.

Lanes, not chaos

One checkout per agent. Protected main branches. Claim the issue before touching code. The rules exist because the lab learned them the hard way — and wrote them down so no agent learns them twice.

Self-healing by morning

Daily fleet health checks at 7am, a CEO brief compiled by the agents about the agents, and error guards that wake the right harness when something drifts overnight.

The method

Autonomy is earned with evidence

Four rules separate this from "AI wrote some code." They're enforced by process, not promises.

RULE 01

Design is decided before code exists

Features start as written RFCs — formulas, invariants, open questions. The human amends and signs off. Only then does any agent write a line.

RULE 02

Green gates or it didn't happen

"Done" means the test suite output is pasted in the report. Claims without command output are treated as unverified — by policy.

RULE 03

The night crew gets audited

Everything merged autonomously faces a second, adversarial review the next day. Defects found become fixes and new tests — the same day.

RULE 04

Every lesson becomes a rule

Incidents turn into written operating rules; repeated workflows turn into graded, reusable skills. The lab compounds — it doesn't just run.
